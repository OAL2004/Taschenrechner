# Einfacher Konsolen-Taschenrechner in Java

Ein kleines Java-Programm, das die Grundrechenarten über die Konsole unterstützt.

## Funktionen
- Addition (+)
- Subtraktion (-)
- Multiplikation (*)
- Division (/)
- Fehlerbehandlung bei Division durch 0
- Endlosschleife, bis der Nutzer das Programm beendet

## Nutzung
1. Projekt in Eclipse öffnen oder in der Konsole kompilieren und starten.
2. Nach Start des Programms erscheint ein Menü:
   - Wähle die gewünschte Operation
   - Gib die beiden Zahlen ein
   - Ergebnis wird angezeigt
3. Wiederhole den Vorgang oder wähle „Beenden“, um das Programm zu schließen.
